# 故事线事实包驱动的报告流转重构设计

## 1. 背景与问题

当前数据对标到报告分析的链路已经具备“先数据、后报告”的基本方向，但实际体验仍然有几个断点：

- 数据对标页的故事线、图片、事实包入口不统一，用户不知道哪些内容已经进入后续报告。
- 每条故事线旁边缺少直接加入事实包的动作，导致数据对标页和报告页之间仍像两个独立模块。
- 图表只能在卡片里看，不能放大，也缺少读图指南，图片无法承担咨询汇报中的“证据主图”角色。
- 结论摘要的“30 秒诊断”没有铺满可用空间，布局像嵌在旧工作台里的模块。
- 专题判断的内容不能自然切换，多个专题堆在一起，重点不够强。
- 结论摘要、证据地图、专题归因和 HTML 报告页没有完全从同一个事实包取数，导致图片、故事、证据句之间咬合不足。

本次重构采用 **A 方案：事实包作为唯一流转中枢**。数据对标页负责发现故事线和生成证据图；事实包负责承接用户选择；后续三页和报告页库只消费事实包。

## 2. 设计原则

1. **每条故事线都有事实包入口**  
   数据对标页不再只有全局“生成数据包”，而是在每条故事线旁边放置 `加入事实包 / 查看事实 / 查看大图 / 读图指南`。

2. **事实包是唯一跨页面状态**  
   结论摘要、证据地图、专题归因、报告页库都读取同一份 `storylineFactPack`，不得各自从页面状态或硬编码文案生成结论。

3. **先选故事，再进报告**  
   用户至少选择 1 条故事线后，才能进入报告分析。没有进入事实包的故事线不应出现在报告页候选中。

4. **图片必须有读图指南**  
   每张可进入报告的图都要绑定 `readingGuide`，说明“看什么、说明什么、用于哪一页、证据来源是什么”。

5. **三页继续简化**  
   结论摘要只回答“核心判断是什么”；证据地图只回答“为什么可信”；专题归因只回答“问题链怎么传导”。其余内容折叠或进入报告页库。

6. **异常状态局部降级**  
   单个故事线缺图、缺 `category`、缺读图指南时，只降级该故事线或该图，不阻塞整页。

## 3. 信息架构

### 3.1 数据对标页：故事线工作区

页面保留数据对标的主视角，但把指标矩阵改成故事线列表。

每条故事线卡片包含：

- 故事线标题：例如 `息差防守压力扩大`。
- 一句话结论：必须来自证据包或指标差异。
- 核心指标：最多 3 个，显示目标行、对标组、差距。
- 证据主图缩略图：展示指标差异或关联指标链。
- 证据强度：强 / 中 / 弱。
- 状态标识：未加入事实包 / 已加入事实包 / 信息不完整。
- 操作按钮：
  - `加入事实包`
  - `查看事实`
  - `查看大图`
  - `读图指南`

页面右侧为事实包抽屉：

- 显示已选故事线数量。
- 显示目标行、对标组、年份。
- 列出已选故事线及其证据图。
- 提供 `进入结论摘要` 和 `生成报告页候选`。
- 若尚未选择故事线，按钮禁用并提示 `请先加入至少一条故事线`。

### 3.2 图片放大与读图指南

点击故事线主图或 `查看大图` 后，打开固定尺寸的图表查看层。

查看层结构：

- 左侧：大图区域，优先使用 `enlargedSrc`，没有则使用 `src`。
- 右侧：读图指南。
  - `这张图看什么`
  - `关键差距`
  - `能支持的判断`
  - `放入报告的用途`
  - `数据来源与口径`
- 底部：`加入事实包`、`用于报告页`、`关闭`。

读图指南不能由渲染层硬编，必须来自 `chart.readingGuide` 或由事实包构建层根据 `facts` 和 `trace` 生成。

### 3.3 结论摘要页：30 秒诊断

结论摘要页改为铺满工作区的单屏诊断页，不再嵌在拥挤的旧模块内。

结构：

- 顶部：事实包上下文条，显示目标行、对标组、年份、已选故事线数量。
- 主区左侧：一句话总判断。
- 主区右侧：3 张以内的主判断卡。
- 下方：最小 KPI 条，只显示与已选故事线直接相关的指标。
- 页面动作：`查看证据地图`、`返回数据对标重新选择`。

生成规则：

- 只读取 `storylineFactPack.selectedStorylines`。
- 优先展示 `priority` 最高且 `evidenceStrength` 最高的故事线。
- 不足 3 张卡时隐藏空位，不补泛化语言。
- 每个判断必须有 `sourceFactIds` 或 `trace`。

### 3.4 证据地图页：事实包证据证明

证据地图页只展示已加入事实包的证据，不展示未选故事线。

结构：

- 顶部：证据包状态、证据强度、缺失字段提示。
- 主区：按证据类型分组：
  - 同业位置
  - 异动偏离
  - 估值/质量锚
  - 结构原因
- 每个证据块显示：
  - 指标名
  - 目标行数值
  - 对标组数值
  - 差距
  - 支持的判断
  - 来源故事线
  - `查看大图` 与 `读图指南`
- 右侧或底部：证据链摘要，压缩为 `位置 → 变化 → 含义`。

如果 `category` 缺失，使用回退归类，但在页面顶部显示 `部分证据分类字段缺失，已按指标口径临时归类`。

### 3.5 专题归因页：可切换专题判断

专题归因页改为专题切换器，一次只展开一个专题。

结构：

- 左侧：专题列表，来源于事实包中的故事线，最多显示 3 个，其他进入折叠。
- 右侧：当前专题详情。
  - 主问题链：结果指标 → 直接原因 → 结构原因 → 管理动作。
  - 证据图：当前专题绑定的 1-2 张主图。
  - 读图指南：当前主图的解释。
  - 报告页候选：1-2 个可加入最终报告的页面。

切换规则：

- 默认选中 `priority` 最高的故事线。
- 点击专题列表后，右侧内容替换，不滚动堆叠。
- 每个专题的说明必须引用事实包中的 `facts / charts / readingGuide / reportCandidates`。

### 3.6 报告页库：只生成事实包支撑页面

HTML 报告页库只接收事实包候选页。

每页必须包含：

- `sourceFactIds`
- `storylineId`
- `chartIds`
- `evidenceSentence`
- `readingGuide`
- `recommendedSlideLayout`

如果某候选页缺少主图或证据句，页面库中显示为 `待补证据`，不生成完整报告页。

## 5. 状态与降级

- `missing-pack`：没有事实包，提示返回数据对标页。
- `empty-selection`：有事实包但没有选中故事线，提示先加入故事线。
- `partial-pack`：事实包存在但缺少分类、图片或读图指南，页面展示可用部分并列出缺失项。
- `stale-pack`：目标行、对标组或年份变化后，事实包过期，提示重新生成。
- `error-pack`：事实包生成失败，显示重试入口。
- `confirmed`：完整展示三页与报告候选。

## 6. 验收标准

### 可自动验证

1. 数据对标页每条故事线都能找到 `加入事实包`、`查看大图`、`读图指南` 操作。
2. `storylineFactPack.selectedStorylineIds` 变化后，结论摘要、证据地图、专题归因都同步变化。
3. 未加入事实包的故事线不会出现在报告页候选。
4. 点击图表能打开放大视图，且读图指南显示 `whatToSee / keyGap / supports / reportUse / source`。
5. 专题归因页切换专题时，只展示当前专题内容，不堆叠所有专题。
6. 报告页候选必须包含 `sourceFactIds / chartIds / evidenceSentence / readingGuideId`。
7. 对包含 `<script>` 的银行名、指标名、读图指南文本，渲染层不得生成可执行脚本。

### 需人工 review

1. 结论摘要是否真的能在 30 秒内读完。
2. 读图指南是否像咨询报告读图说明，而不是技术字段解释。
3. 三页是否明显比旧版更聚焦。
4. HTML 报告页是否形成完整故事，而不是事实块拼贴。

## 7. 实施分期

### Sprint 1：事实包中枢与基础交互

- 建立 `storylineFactPack` 模型。
- 数据对标故事线卡片增加事实包入口。
- 增加图表放大与读图指南。
- 三页读取同一个事实包并完成最小同步。

### Sprint 2：三页布局重构

- 结论摘要铺满屏幕。
- 证据地图只展示事实包证据。
- 专题归因改为可切换专题。
- 增加空状态、过期状态、字段缺失状态。

### Sprint 3：报告页库接入

- 报告页候选只来自事实包。
- HTML 报告页使用事实包中的图、证据句和读图指南。
- 增加“加入最终报告”的选择空间。

### Sprint 4：视觉和内容精修

- 优化咨询风格图表资产。
- 增加故事线图谱、链式归因图、证据主图模板。
- 对读图指南和报告页文案做人工 review。
